# Packet Host (Equinix Metal)

> Packet Host, Inc. (packet.com / api.packet.net) was a New York-based
> bare-metal cloud provider backed by Battery Ventures. Equinix acquired Packet
> in 2020 and rebranded it Equinix Metal. Equinix Metal was sunset on
> 2026-06-30; its REST API (api.equinix.com/metal/v1) still authenticates but no
> longer permits new resource creation. This profile captures the Metal API
> surface and its lineage.

## API
- [Metal API (OpenAPI 3.0)](openapi/packet-host-metal-openapi-original.yml): 220 operations across 40 tags — Devices, Projects, Organizations, IP Addresses, Ports, VLANs, VRFs, Metros, Facilities, Plans, Operating Systems, SSH Keys, Events, Capacity, and more. Base URL https://api.equinix.com/metal/v1. Auth: X-Auth-Token API key.
